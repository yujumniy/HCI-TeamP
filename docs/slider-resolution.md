# 2026-11-25 입력 단위 수정

교수님 피드백 및 사용자 요청으로 C2·C4 슬라이더를 1단위 정수값으로 변경했습니다. C1 물리 버튼·C3 터치베젤은 5단위 유지합니다. 범위는 0~100이며, 손잡이를 잡고 드래그하는 규칙·트랙 탭 차단·상대 잡기 오프셋·길이·속도 배율은 유지합니다. 이 수정은 정수 반올림 해상도 변경이며 드래그 속도를 증폭하지 않습니다.

- START raw의 input_policy=SLIDER_1_BUTTON_BEZEL_5_V1, volume_step=1 또는 5로 실제 시행 설정을 보존합니다.
- 새 trials.csv에 input_policy, volume_step 열을 추가했습니다. 예전 기록은 LEGACY_5, 5로 내보냅니다. 원본 DB/해시/기존 백업은 수정하지 않습니다.
- 입력 단위 검증은 기록된 정책과 조건을 따릅니다. C1·C3의 비5배수는 계속 오류입니다.
- 기존 설정으로 시작한 미완료 참가자는 새 설정으로 이어갈 수 없습니다. 기존 기록을 보존하고 새 참가자로 시작합니다. 완료된 기존 참가자는 그대로 내보낼 수 있습니다.
- 촬영용 DEMO와 정상 실험 모두 새 입력 단위를 사용합니다. 폰과 워치를 함께 업데이트해야 합니다.
- 목표값·과제 수·제한 시간·휴식·C3 CLICK 진동은 유지합니다.
- 지표는 정수값 차이로 계산하므로 오버슈팅 1, 최종 오차 1도 보존합니다. 건너뛴 중간값은 생성하지 않습니다.
- 실기기 검증: C2/C4에서 41·42 등 값 표시, 0/100 끝점, 손잡이 이외 탭 차단, C1/C3의 5단위 유지, 폰·워치 저장/동기화/백업 확인.
- 새 버전으로 외부 참가자 1~2명에게 프로토콜 전체 예비실험 후 감도·소요시간 점검. 기존 5단위 파일럿 결과와 새 결과를 동일 조건으로 합치지 않습니다.
