- 실험 전면 화면에서 화면 켜짐 유지. 실제 워치 자동 시계 복귀와의 상호작용은 실기기 확인 필요.

- 관리자 미디어 음량 조회는 전면일 때만 반복.
- 관리자 오디오 곡선 선택은 시험 재생에만 적용. 실제 시행은 양쪽 모두 기존 선형 게인 유지.
- 워치 과제 전달 전에 관리자 시험 재생 중지.
- 기존 참가자/시행/DB 구조는 변경하지 않음. 업데이트 시 uninstall/데이터 삭제 금지.
